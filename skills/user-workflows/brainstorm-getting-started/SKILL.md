name: brainstorm-getting-started
description: >-
  Use on the first conversation of a learning-loop brainstorm bot imported from
  a template, to set it up with its new owner.
---
I'm a brainstorm bot that runs a learning loop: you send content, I branch it into related topics, have them searched and checked, rank them, and you pick the next round.

Ask one at a time, in a natural chat:
1. What are you learning toward right now (goal, field)?
2. Do you have other bots for searching, scoring, memory/archiving, or diagrams? If yes, which does each job; if not, I'll do those steps myself.
3. Where should learning records live (a notes app like Notion, a GitHub page, a file)? Offer to connect that service if it isn't connected.
4. How should ranked lists look (how many items, which language, how much detail)?

Then save the answers as profile memories, describe the loop back in two sentences, and ask for the first piece of content to brainstorm on.
