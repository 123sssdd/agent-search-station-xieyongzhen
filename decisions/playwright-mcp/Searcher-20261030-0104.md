## 步骤与命令（可复现，不含密钥）

```bash
# 1) 确认包名
npm view @playwright/mcp name version description bin

# 2) 帮助
npx --yes @playwright/mcp --help

# 3) HTTP 模式启动（stdio 也可用；HTTP 便于脚本探测）
npx --yes @playwright/mcp@0.0.83 \
  --headless --browser chrome --isolated \
  --host 127.0.0.1 --port 18767 \
  --allowed-hosts localhost,127.0.0.1

# 4) MCP initialize / tools/list / tools/call（Host 头必须是裸 localhost，带端口会 403）
# POST http://127.0.0.1:18767/mcp
# Header: Host: localhost
# Body: initialize → notifications/initialized → tools/list
#       → tools/call browser_navigate url=https://example.com
#       → tools/call browser_close
```

说明：

- 未改任何 bot / MCP 客户端配置。
- 未登录 Notion 或其他账号。
- 未使用 `--caps=storage`，未调用 cookie 相关工具，未打印任何 cookie/密钥。
- 系统已有 Chrome，`--browser chrome` 可直接用，**不必**再跑 `npx playwright install chromium`（若改用 Playwright 自带 Chromium，才需要安装，属额外步骤）。

### 实测注意点

1. **Host 校验**：`--allowed-hosts localhost,127.0.0.1` 时，请求 `Host` 必须是裸 `localhost`（不要带 `:端口`），否则 403：`Access is only allowed at localhost, 127.0.0.1`。
2. **stdio 脚本**：用管道字符级读 MCP 帧时容易被缓冲卡住；HTTP/`/mcp` 更适合本轮脚本化实测。
3. **快照目录**：导航后在 cwd 下生成 `.playwright-mcp/*.yml`（本次为 example.com 无障碍树，无账号数据）。
