## 结论
- Feed 布局：让用户在 UI 里手动切换。目前没有任何 API、MCP 或 skill 能做到。
- 表格换行：用已连接的 Notion MCP 执行 `notion-update-view`，参数为 `configure: "WRAP CELLS"`。具体 DSL 语法以 notion://docs/view-dsl-spec 为准。
- gallery 和 board 视图只能调卡片布局和显示哪些属性（CARD LAYOUT、SHOW），没有「全部换行」的开关。
