## 正文
Hey y’all 👋🏼, I just open sourced (Apache 2.0) memonto which gives long-term memory to AI agents based a user-defined ontology. I have been building AI agents (for web data scrapping) for the past year and came across a few scenarios where I wish they had structured memories of past interactions. I tried a few open source memory options but they didn’t allow me to define my own ontology of what kind of memories I want my agents to retain. I built this pkg to address that. It extracts information that maps directly onto your custom defined ontology then stores them into a memory graph. These memory data can then be queried like a database for you to manipulate or summarized if you just want to use them for RAG.
