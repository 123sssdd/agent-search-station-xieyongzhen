## 结论
- 能否实现：**Feed 布局用官方 API/MCP 做不到**（create-view 的 type 枚举里没有 feed，changelog 也没提）；**表格视图的属性换行可以用官方 API 做**（PATCH /v1/views 的 configuration.properties[].wrap 和 wrap_cells）。gallery/board 的「换行显示所有属性」在 API 里没有对应字段。全网没找到能改 Feed 的 skill 或 MCP。
- 推荐路径：① Feed：用户在 UI 里手动加（/Feed view 或 添加视图 → Feed，约 1 分钟），Feed 本身会完整显示属性；② 表格换行：用官方 Notion MCP 的 notion-update-view 或 API PATCH /v1/views 设置 wrap_cells=true；③ 如果必须自动化 Feed，再考虑 Playwright 在已登录浏览器里点选。
